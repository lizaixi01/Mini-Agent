# 第 5 课：Memory

会话记录保存一段对话；项目记忆保存可供不同会话参考的信息。当前实现保存在本机 `.mini-agent/memory.json`，不自动整理历史。

体验：运行演示，输入 `记住 我喜欢用小例子`，确认是否保存；输入 `/memory` 查看，`/forget 1` 删除第一条。也可以用 `/remember 内容` 手动保存。

搜索 [agent.py](../agent.py) 中的 `load_memory`、`save_memory` 和 `propose_memory`。模型只是提出记忆；程序得到 `y` 后才写入文件。演示根据关键词运行固定剧本，真实模型是否调用工具需要实际验证。

删除记忆只会停止未来从记忆文件读取它；如果同样的信息已经出现在对话历史中，历史不会被删除。不要把密钥写入记忆。
