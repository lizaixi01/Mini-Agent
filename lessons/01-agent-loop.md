# 第 1 课：Agent 循环

Agent 的基本过程：收到任务 → 决定下一步 → 使用工具 → 观察结果 → 继续或回答。

打开 [agent.py](../agent.py)，搜索 `run_agent` 和 `run_command`。`run_agent` 控制循环；`run_command` 用 `subprocess.run` 执行命令，返回正常输出、错误输出和退出码。退出码为 0 通常表示命令正常结束，不代表整个任务一定完成。

体验：运行 `python agent.py --demo`，输入“查看文件”，阅读显示的命令，再决定是否输入 `y`。演示是固定剧本，批准后会运行真实命令。

想一想：模型提出的命令为什么不能直接执行？程序为什么需要把结果告诉模型？
