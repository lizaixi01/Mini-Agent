# 第 2 课：工具调用

模型可以直接回答，也可以请求程序调用工具。项目中有三个工具：`run_command`（执行命令）、`read_skill`（读取技能）、`propose_memory`（提出记忆）。

搜索 [agent.py](../agent.py) 中的 `TOOLS` 和 `tool_call_id`。工具定义说明名称和参数；程序收到请求后检查参数，再把结果通过调用编号交回模型。

体验：运行演示，输入“解释 print 是什么”，观察模拟模型请求 `read_skill`。演示只展示流程，不会真的理解或解释代码。

想一想：如果模型请求一个不存在的工具，或者参数不是所需的字符串，程序该怎么办？
